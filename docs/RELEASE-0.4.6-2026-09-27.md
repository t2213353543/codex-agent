[OpenAI 官方缓存文档](https://developers.openai.com/api/docs/guides/prompt-caching)说明缓存要求匹配可复用前缀；这是稳定工具和历史内容的依据。BPS 的具体表现另行通过真实请求验证，不把普通 API 文档直接当作该入口的协议证明。
