# Admin Key 管理接口完善

本轮覆盖 32 条管理路由：账号导入/预览/批处理/刷新/详情/日志、分组、普通 API Key、代理与检测、系统设置、管理会话、密钥轮换、概览、诊断及操作审计。调用规则与请求示例见 [API-CONTRACT.md](API-CONTRACT.md)。

- 显式 Bearer 优先；错误、空或重复 Authorization 不降级到 Cookie。合法 Bearer 不受过期 Cookie 或 Redis 会话故障影响。普通网关 Key 无管理权限。
- Cookie 写请求和登录校验 Origin，查询与注销使用实际认证身份。Admin API 开关只控制管理员密钥调用模型网关，关闭后仍可管理系统。
- 轮换支持原端点、同 request_id、24 小时内的响应丢失恢复，仅当前仍有效的轮换结果可重放；PG 事务及文件锁内重新验证调用者，阻止并发轮换使用已撤销密钥。已有浏览器会话按原生命周期保留。
- 网关按权威 PG 密钥验证 Admin Key，另一实例轮换立即撤销旧值；现有 WS 每轮权限检查复用同一规则。设置页读取当前密钥掩码。
- 所有管理错误包含结构化 code；未知路由404、方法错误405保留 Allow。普通Key更新返回元数据和掩码，不再返回完整密钥；仅创建时展示新密钥。

## 验证

普通全库 Go 测试 536 项通过、36 项依赖环境或显式 opt-in 跳过；go vet 与 Linux amd64 构建通过。跳过项没有伪报为成功。

另以实际隔离 PostgreSQL/Redis 执行 Linux race：39 个顶层测试、124 项含子测试通过，0 失败、0 跳过。覆盖完整管理路由权限矩阵、认证优先级、Cookie/Origin、轮换失败/重放/并发撤销、跨实例权威密钥、PG/Redis 会话、粘性与 WebSocket。证据：`.local/settings-deploy/linux-race-20260917T132057/report.json`，对应后端文件哈希完整保存在同目录 `source-manifest.json`。测试仅用合成凭据、隔离存储及本地受控上游。

实际部署结果另记录在本轮发布清单；本说明中的测试通过本身不代表已切换生产。生产验收保留现有 Admin Key，不为测试轮换用户正在使用的密钥。
