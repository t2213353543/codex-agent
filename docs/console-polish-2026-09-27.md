# 控制台调整与验收

本次修改覆盖用户提出的 10 项需求。

| 项目 | 实现 |
| --- | --- |
| 接入指南与接入卡片 | 删除页面、路由、导航入口、`console-connect-card` 及对应样式 |
| 夜航快捷栏 | 删除 `console-rail`，保留统一侧栏与折叠/手机导航 |
| 模型一致性 | 在模型列、手机列表与详情比较真实 `sent_model` / `returned_model`；区分一致、不一致、未能校验，导出保留状态 |
| 上海时间 | 统一显示、日期筛选、今日起点、租期输入、代理/归属地检查时间、导出日期及默认统计时区；显式指定的日历分桶时区仍可使用 |
| Token 单位 | K/M/B/T 缩略显示；使用记录提示保留精确数值，未知值不转为零 |
| 导入配置 | 移除高级配置中的 Token 额度与窗口天数控件 |
| 官方窗口美元金额 | 按官方窗口边界汇总本地留存请求，分别计算非缓存输入、缓存输入、输出成本；覆盖优先档位和长上下文 |
| 分组展示 | 单行省略；悬停或键盘焦点显示完整分组 |
| 账号 hover | 移除账号表格行悬停变色与过渡 |
| 运维监控 | 真实请求吞吐、成功率、耗时/首 Token 趋势与分布、错误、当前并发、CPU/内存、Go 运行时、PG/Redis 连接池、用量写入健康；支持范围切换与自动刷新 |

上海时间使用 `Asia/Shanghai`；查询接口仍传 Unix 时间。后台今日统计默认上海，可用 `STATS_TIMEZONE` 显式覆盖。浏览器设备时区不会改变上海日期输入的含义。

窗口美元金额是参考价格对留存请求的本地估算，已明确标注；缺少用量、模型价格或可靠的多模态细分时显示未估算/已知部分，不由官方使用百分比推算账单。详见 [计算说明](account-window-usd.md)。

运维资源指标区分操作系统视图与当前 Go 进程；容器中系统指标可能反映宿主机。CPU 第一次采样没有利用率，等待下一次采样后计算。Windows 使用系统 API，Linux 读取 `/proc`；其他平台显示未采集。

## 一键复验

在项目根目录运行（需要 Go、Node.js、npm、Chrome 及已安装的前端依赖）：

```powershell
python tools/verify_console_polish.py
```

依次运行前端单测、生产构建、Go 测试，以及导航、使用记录、账号、运维四组浏览器检查。报告与日志位于 `.local/console-polish-verification/`；浏览器使用合成 API 数据，不调用生产服务。

重点覆盖 UTC/洛杉矶/上海环境的跨日时间与筛选往返、两种主题和多种屏幕宽度、键盘焦点提示、模型观测归属、窗口计价边界与缓存刷新、监控切换/失败/空样本。Windows 主机资源探针通过实际调用验证；Linux 采集代码交叉编译通过。

数据库集成用例在配置隔离的 `TEST_DATABASE_URL` 后执行；本次本机未配置该环境，相关用例跳过，不能作为 PostgreSQL 实测证据。

本次统一复验结果：7 个步骤全部通过，前端单测 185 项通过，Go 全包测试通过，4 组浏览器检查通过。最终报告为 `.local/console-polish-verification/report.json`。运维稀疏耗时样本显示点标记的最终构建记录见 `.local/operations-monitor-20260927/frontend-build.txt`；该图表修正后重新构建并通过运维浏览器检查。
