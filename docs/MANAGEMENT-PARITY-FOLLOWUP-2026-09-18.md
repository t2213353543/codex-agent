## 本次实际完成

- 错误工作区：同条件查询失败与中断记录，按未处理/已处理过滤；备注、标记已处理、重新打开、最近 50 次版本历史及累计历史数。并发编辑采用版本检查，审计失败回滚；处理标记不改变原请求结果、账号状态或累计用量。
- 长上下文参考价：严格输入总量大于阈值才触发，输入已含缓存；分别应用输入/输出倍率，对整次请求计价。详情、全量统计、排行、价格快照、CSV/JSONL 口径一致，CSV 追加五项价格档位证据。无价格来源仍显示未知，未添加官方假定价。
- 账号只读运行详情：当前实例并发、连接/指定模型冷却、OAuth 刷新等待及共享 Redis 来源；明确未检查模型、存储不可读和实际全局策略。读取不清理冷却或触发凭据刷新。
- 最近业务请求：可选列按稳定账号 ID 批量读取。PostgreSQL 使用持久 usage_events 的真实事件时间，文件模式使用留存详情；未匹配为 null，接口错误不伪装成从未使用。
- IP 归属地：单条与当前页去重批量查询，明确点击才发送公网 IP 至 GeoJS。固定来源、禁止跳转、不转发账号或管理凭据、24 小时内存缓存、每批最多 50 个、支持取消和逐项失败。私有与保留地址不外发。测试使用替身，不是 GeoJS 实网可用性承诺。
