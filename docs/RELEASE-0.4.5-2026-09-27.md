## 已上线的改动

- 仪表盘用实时 RPM/TPM 替换请求失败率卡：最近 60 秒、5 秒刷新；token 只使用已完成请求的真实上游用量，缺失明确标记。
- 普通 BPS SSE/JSON 的最终 usage 原先没有写入使用记录。现在输入、输出、缓存、缓存写入、推理用量及返回模型从实际响应入账；测得零与未知分开。

- 移除 BPS 请求、事件和续聊存储的旧大小/数量上限；账号并发继续执行。
- 认证失效、不可用账号继续按原优先级和权重选择候选；首个可见输出之后不跨账号重放。WebSocket 的真实响应 ID 及时送达，取消不会等待首字。
