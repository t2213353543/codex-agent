# Codex 账号管理操作与验收

本轮提供现有 Codex OAuth 账号可独立实现的管理操作，页面继续使用已恢复的蓝色旧壳和连续账号列表。部署状态由最终发布报告记录，本文本身不表示已经上线。逐条参考与边界见 [账号对齐矩阵](ACCOUNT-PARITY-MATRIX.md)。

## 操作入口

| 入口 | 能力与口径 |
|---|---|
| 添加账号 | 浏览器 OAuth 回调、刷新令牌、移动端原 client_id、session/auth.json、Codex PAT；凭据准备成功后再填写名称、备注、标签、启停、分组和容量字段。保存冲突保留加密 ready 会话可重试 |
| 导入账号 | 保留原 token 行、别名、auth.json、多文件、JSONL、Sub2API 封套；预览及逐项结果支持既有流程 |
| 筛选与排序 | 服务端全结果排序和精确总数；支持状态、分组/代理、标签、启用、refresh 有无、到期范围、训练隐私确认。隐私未知不等于已开启训练 |
| 本页 / 全部选择 | 全部结果选择固定 ID 与版本；换页保留选择，筛选变化清空。单次全选上限 10000，超限明确拒绝 |
| 批量编辑 / 更多操作 | 明确勾选修改字段；启停、组/代理、标签、数值配置、删除、刷新令牌、批量额度/模型读取、按 ID 替换凭据。更新/删除每批100，刷新/上游读取/凭据替换每批10 |
| 单账号更多操作 | 用量、模型目录、真实SSE/compact测试、定时检查、使用统计、独立账号租期、OAuth或JSON重新授权 |
| 账号详情 | 管理字段、最近留存请求、身份邮箱/workspace/user/agent来源。JWT和导入声明明确未验证；近期请求首条不是清理前全历史使用时间 |
| 今日用量 | 按浏览器时区的今日零点至当前时刻，批量统计当前页账号的留存明细。未取得与真实零请求分开，费用未知不填0 |
| 迁移备份 | 元数据清单、可恢复凭据、可选所关联分组/代理定义；代理用户名密码单独确认；CRS只预览和同步Codex OAuth |

## 实际上游动作

打开账号用量窗口只读取已保存检查记录。点击读取额度或模型目录才连接上游，且不发送推理。模型目录列出的模型不能当作推理测试通过；SSE和compact检查分别保存真实终态，HTTP200中的失败事件仍显示失败。

推理测试与启用推理计划有明确的额度消耗确认。定时计划使用填写的IANA时区或UTC；结果可能为成功、失败、已跳过、结果未知，进程中断不自动重放推理。计划不解除人工停用，不修改业务请求历史。

人工兑换先读取真实有效券，选择具体券并确认不可退回。重试同一张券沿用操作ID；结果未知时需查询上游核对，不能认为未消费。自动重置策略默认关闭，启用须确认自动消费；主窗口或次窗口任一达到配置阈值时由独立管理任务判断和兑换。未知结果会暂停，重新启用须明确核对确认。关闭策略只阻止后续任务，不撤回已经发出的兑换。

账号租期与登录令牌到期分别管理。延长租期只有在账号仍保持该租期自动停用的精确版本时才安全恢复；人工改动或凭据变化后保持停用并提示原因。

## 跨实例恢复

1. 导出时选择可迁移凭据；需要同时迁移关联资源时勾选资源定义。认证代理的用户名密码需额外勾选并单独确认。仅有资源定义而无代理密码时，应映射到已配置的本地代理。
2. 在“恢复凭据备份”读取文件，明确本地映射。资源阶段先预览，再创建或映射；同名资源不会被覆盖，未包含代理认证信息的项会明确失败。
3. 返回的实际资源映射进入账号阶段，再生成账号预览并确认恢复。新增账号恢复配置；同名替换只更换凭据，保留本地管理配置。

两阶段可能部分成功，已创建资源不会因账号失败而自动撤销。资源提交结果未知时需刷新资源并手动映射，界面不会直接重发创建。预览与结果不显示代理密码、访问令牌或Agent私钥。

纯Agent私钥认证需要本项目尚无的任务签名协议，不能只导入私钥就作为Bearer账号使用。OAuth tokens附带的agent_identity仅保存非秘密身份摘要；不改变Codex网关的认证或转发行为。
