# 管理设置恢复与自定义功能验收

已补齐回退旧界面后丢失的设置入口，沿用旧界面的单栏白色卡片。页面现在提供 20 个可编辑配置：13 个开关、4 个数值输入、2 个模式选择和提示词编辑器，另保留管理密钥轮换与系统信息。

恢复 WebSocket、CLI 请求身份与 Linux/macOS 配置、内置提示词、粘性会话与期限、稳定缓存键等原有设置。新增 11 个配置：HTTP SSE、HTTP JSON、上下文压缩、模型列表、请求兼容转换、临期令牌自动刷新、上游 401 恢复、提示词注入模式、流式读取空闲超时、响应头超时和压缩超时。字段、默认值与范围见 [网关设置](GATEWAY-SETTINGS.md)。

## 生效与保存

- 入口关闭在选取账号之前返回 403，不向上游发请求；原生 WebSocket 独立控制。
- 临期刷新和 401 恢复独立控制。关闭自动刷新仍可使用未过期令牌；管理端手动刷新仍可用。
- 提示词支持前置、后置、仅为空时补充，重复处理不重复注入。兼容转换可独立关闭。
- 三类 HTTP 超时采用每次请求的设置快照，不修改正在被其他请求共享的 transport。默认值保留现有连接池；自定义 header timeout 的 transport 在响应结束后清理。
- 开关与选择即时保存；文本和数值显式保存。版本冲突返回 409，刷新后保留全部未保存草稿；失败或无有效确认不会显示保存成功。
- 普通 HTTP 站点缺少 `crypto.randomUUID()` 时，用 `crypto.getRandomValues()` 生成轮换请求 ID；失败重试沿用相同 ID，避免重复轮换。
