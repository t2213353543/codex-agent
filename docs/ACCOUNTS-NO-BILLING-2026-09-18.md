# 账号管理无计费范围

本轮按最新明确要求撤下所有账号金额功能。此前采购、售价、倍率与多区间价格对齐任务停止，不再将其作为待实现目标或当前验收要求。历史数据文件与冻结候选没有删除或覆写。

## 当前界面

- 账号列表、详情、今日统计不再显示采购成本、售价、参考金额或定价状态，没有对应入口。
- 账号统计保留请求、成功/失败/中断、Token、缓存、推理/写缓存Token、总耗时、首Token耗时、IANA日历统计、活跃日/自然日均值、所有并列峰值日、请求/Token两种趋势和逐日数据。统计校验不再要求金额字段。
- 普通账号导入保留所有原文件格式、逐项替换确认与外部租期识别。没有 `include_external_costs` 选项或请求参数，也没有成本恢复回执面板；原始金额扩展字段只保留忽略提示，不应用到权重。
- 导出仅支持账号、凭据独立确认、分组/代理资源、代理密码独立确认和租期。没有 `include_costs`；兼容旧响应时也在内存中剥离该管理段。
- 恢复旧备份时，`accountBundleInput` 去掉 `management.costs` 后才请求预览/导入，保留同文件的账号凭据、资源、Token额度和租期，不修改原文件。没有成本恢复调用；账号阶段、资源阶段与租期独立确认保持。
- OAuth授权/刷新、上游用量/模型查询、手动/定时测试、真实额度与重置券、独立租期均保留。这些是账户可用性和用量管理，不因撤下本地金额功能被误删。
