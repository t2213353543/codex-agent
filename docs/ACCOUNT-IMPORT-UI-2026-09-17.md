# 账号导入与弹窗优化

修复 Sub2API 导出文件无法直接预览，以及前端提交时丢失账号配置的问题。导入支持 Sub2API `accounts` 导出、Codex `auth.json`、嵌套 `credentials` / `tokens`、JSON 数组、JSONL、每行 Token 和 `名称----Token`。

## 导入行为

- 可多选或拖入文件，也可粘贴内容；统一上限 32 MiB、10000 个账号。
- 预览不写入；各条账号独立返回结果，格式错误文件不会阻止其他有效账号导入。
- 并发、优先级、权重、备注、标签、启用状态及本地同义配额配置得到保留；导入默认值仅补缺，可明确选择覆盖源配置。
- 同 Token 默认跳过；同名账号默认跳过，必须逐项选择替换已有凭据。替换保留现有账号管理状态。
- 仅支持 OpenAI OAuth 账号。Sub2API 计费倍率、模型映射、自动暂停及扩展设置不会错误地变成网关调度配置，预览显示相应说明。
- 外部代理和分组 ID 不当成本地 ID 使用；导出账号明确绑定代理时，必须选择本地代理替代。导出包中的代理不会自动创建。
- 账号管理到期日与访问令牌到期时间分开处理；后者读取凭据字段或访问令牌 JWT。错误信息与下载结果不包含凭据。

## 界面

导入弹窗采用上传/粘贴切换、三个阶段、可折叠高级配置及逐项结果。弹窗、抽屉、确认框和复制回退框统一标题、表单、页脚、关闭按钮及状态样式。修复路由懒加载样式覆盖，补齐单选、数字输入、选择器等共享组件 CSS。支持四套主题与窄屏固定页脚，移动端导入主按钮独占整行。
