# 管理功能范围：不包含计费

2026-09-18，用户明确要求本项目不需要任何计费。本说明优先于此前对齐矩阵、定价审查和阶段验收中的计费待办；旧报告只证明当时的候选，不代表当前需求。

## 移除范围

- 参考价、采购成本、渠道售价、计价组、倍率、分时价、阶梯价、上下文价格区间及费用图表。
- 账号成本编辑、外部倍率迁移、成本备份恢复，以及列表、详情、统计、CSV/JSONL 中的金额输出。
- 相应前端组件、API 调用与后端计算实现退出活动源码。历史代码和计费测试保留在 `.local/retired-billing-20260918`，不把已退役测试算作通过。

## 保留范围

账号授权与凭据管理、分组/代理/KEY、运行状态、真实上游配额、重置券、租期、定时检查、资源备份恢复继续保留。使用记录继续提供请求与 Token/缓存统计、时延/TTFT、模型与路径观测、错误处理、筛选、快照、清理和脱敏导出。

本轮不改变 Codex 网关转发、指纹、协议、调度、重试及原始记录写入。`service_tier` 等真实请求观测不是定价功能，继续保留。历史已存计费文档不读取、不改写、不删除；原始记录中的上游金额/预算观测只从管理输出中省略，不回写历史记录。

## 接口兼容

- 已退役的 `/api/logs/pricing`、`/api/logs/cost-rules`、`/api/logs/sale-policy`、`/api/logs/cost-policy` 和 `/api/accounts/import-costs` 路径及子路径返回 404，不允许落入动态账号或日志 ID 路由。
- 账号导出 `include_costs: true`、外部导入 `include_external_costs: true` 返回 400，且不写入账号。省略或 false 不妨碍普通导入导出。
- 旧账号 bundle 的 `management.costs` 被忽略，其他账号、资源、租期结构仍严格校验。原始导入文件不修改。
- CSV 使用 `X-Export-Schema: codex-usage-v3`，只含身份、用量和运行观测。JSONL 不含 `cost`、`account_cost`、`sale_cost`、`usage_amount` 或 `rollout_budget_units`。
- 快照只固定请求记录范围，不再读取或保存价格目录。

## 验证边界

新验收只覆盖保留的非计费功能，并额外验证计费路由关闭、历史计费数据保持原样和旧备份兼容。合成上游与本地 PostgreSQL/Redis 不等于生产可用性证明。当前候选未部署，既有网关任务的独立发布验收不能被本管理验收替代。
