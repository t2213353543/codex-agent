## 后端管理接口

- `GET /api/diagnostics`：复用现有管理认证，返回版本、运行时间、存储方式和依赖状态。PG/Redis 并行检查共用 2 秒响应预算，错误为固定代码，不返回 DSN、地址、凭据或底层错误。
- `GET /api/audit-logs`：读取现有 `audit_logs`，不新增表或写入审计事件。支持 `action,entity_id,from,to,limit,cursor`，每页最多 200 条，按微秒时间与 ID 倒序翻页；游标绑定筛选，避免跨筛选误用。文件模式 `supported:false`；数据库故障返回明确错误。

审计页展示的是已经持久化的操作，不能由此推断完整的失败操作/登录事件审计覆盖。诊断不调用模型，管理认证失败时也不会绕过认证暴露运行信息。

## 参考与实现边界

参考 Sub2API 本地 `current-source/frontend` 中账号/用量页的筛选分页与管理布局，以及 [CPA 官方管理中心](https://github.com/router-for-me/Cli-Proxy-API-Management-Center) 的资源管理、日志与诊断组织方式。实现继续使用本项目 Vue 3 / Element Plus / Go 及现有管理 API。

本轮开发未使用真实账号或发起模型推理。用户随后授权上线，最终 release-dist 已于 2026-09-17 21:59（Asia/Shanghai）发布；55 个静态文件与验收包一致，后端二进制保持现网原哈希。真实浏览器桌面/手机、登录退出及管理 API 验收通过，见 [最终上线记录](MANAGEMENT-UI-RELEASE-2026-09-17.md)。此前 21:39 的较早界面快照已被本次替换。
