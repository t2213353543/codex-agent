# 账号绑定成本配置备份与恢复

本轮只迁移本系统账号绑定的管理成本配置，不改变网关，不执行扣费，不将代理或登录凭据解释成采购来源。参考 Sub2API `account_data.go:212/446` 的账号 `RateMultiplier` 实际导出/导入路径；本站倍率属于独立管理策略，因此恢复需显式映射稳定账号 ID 并确认，而不是写进网关账号字段。

## 导出范围

凭据备份中新选项“包含账号绑定的成本配置”默认关闭。启用后 `include_costs:true` 导出所选账号的 account-target 单目标费率全部历史版本（含来源、四桶价格、倍率、阶梯），以及当前已生效且启用的有序策略中为该账号明确配置的倍率快照。

不包含全局渠道、分组、有序采购规则、默认倍率，也不推测未配置账号倍率。成本选项不扩大登录凭据/代理密码授权范围，原确认步骤保留。费率与显式零倍率保持原值，不用售价填补未知采购成本。

`management.version=1` 中 `costs` 与 `leases` 可独立存在；旧备份不含管理段仍可导入。非法索引、重复账号项、组目标费率、全局字段、敏感额外字段和不完整价格在写入账号前阻止。

## 分阶段恢复

1. 预览/恢复账号按既有流程执行；成本不自动应用。实际返回 `cost_restore` 回执，将备份账号序号绑定新本地稳定 ID 与账号版本。
2. 成本面板默认不启用，可跳过。启用后可逐项选择，仅处理 `pending` 且尚有可恢复部分的条目。
3. 展开“查看将恢复的成本配置”，核对模型/服务层、每个历史版本和生效时间、四桶费率、阶梯、原来源与供应方，以及显式账号倍率来源。内容仅以文本渲染，不展示任何账号凭据。
4. 先预览，再勾选确认应用到已固定账号 ID。已有目标模型/服务层费率不覆盖；费率失败但倍率仍可恢复时，允许单独完成倍率部分。
5. 恢复显式账号倍率额外确认新增后续完整策略版本，保留其他账号和规则。未确认时可只恢复费率，倍率明确跳过；目标无启用策略时不会自动启用，逐项回执说明跳过原因。

每批最多100项，可停止后续批次。账号、租期、成本分别提交，部分失败不撤销已完成阶段。`applied/partial/failed/running/unknown` 均不会重新变成可提交项；未知结果只能读取回执核对，禁止自动重发。回执刷新核对固定账号、版本、规则数量、倍率存在性及规范化配置 JSON，不能悄悄换目标或金额。策略观测版本可以向前变化，不错误要求本批其他账号新增版本后全局目录版本仍完全不变。
