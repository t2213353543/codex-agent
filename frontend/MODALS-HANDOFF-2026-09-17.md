# 弹窗与组件样式验收

统一重做管理界面弹窗、抽屉、确认框、手动复制框及其输入、选择、单选、多选、数字输入、错误提示、关闭按钮和页脚。四种主题共用结构，深色使用独立表面、边线及遮罩色；窄屏保留固定页脚和可滚动内容。分组、代理、密钥、日志弹窗补充说明及顶置标签，删除确认使用危险按钮样式。

入口显式加载共享弹层及控件样式，全局主题规则使用稳定优先级，避免路由懒加载的 Element Plus CSS 覆盖应用样式。仍保持组件按需加载，没有引入整包 CSS。

## 验证

`npm --prefix frontend run test:modals`：生产构建后，在独立本机静态服务上启动 Playwright，全部 API 使用合成数据。禁止未拦截请求与外部网络请求，不读取真实账号或密钥。

12 种界面 × light/dark/ocean/mint × 320/1440 px，共 96 组：代理表单、分组表单、删除确认、密钥选择下拉、创建成功、手动复制、账号导入初始、Sub2API 合成导出预览、显示列、编辑账号、保存日志筛选、日志抽屉。检查视口边界、内容横向溢出、组件样式、单选交互、选项弹层、复制回退焦点、关闭恢复焦点和浏览器错误。
